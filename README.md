# 桌宠工具箱 v0.4

一个使用 Python + PySide6 编写的 Windows 桌面宠物，也是截图、贴图、图片历史、快速计算和便签的轻量入口。支持本地文字提取、Ollama 图片翻译及译文覆盖、DeepSeek API 文字对话。v0.4 新增截图标注、区域取字、贴图锁定 / 穿透 / 工作区、计算记录 / 收藏、选中文字提问、Q / Rp / VCO FoM 与全屏免打扰。应用不提供账号、云同步或插件系统。新增入口及验收步骤见 [FEATURES.md](FEATURES.md)。

界面现已统一为 Luna 浅色主题：冷灰背景、白色圆角卡片、少量莓红强调、分级按钮和轻量悬停动效。各工具窗口使用共用主题，设计结构见 [UI_DESIGN.md](UI_DESIGN.md)。退出旧进程再启动即可加载，无新增依赖；本次没有运行应用，实际视觉与交互由用户验收。

## 安装

### 从 GitHub 获取完整项目

动画 PNG 使用 Git LFS。安装 Git for Windows（包含 Git LFS）后，在命令行克隆仓库，并进入项目目录执行：

```powershell
git lfs install
git lfs pull
```

请使用 Git 克隆获取完整素材；GitHub 的普通 ZIP 下载可能只包含 LFS 指针。完整运行素材约 678 MiB，另有动画源工程。仓库排除了虚拟环境、用户数据、构建缓存和第三方 Godot 可执行文件。日常运行无需 Godot；仅重新构建素材时，需要自行把与原工程匹配的引擎放入 `Luna_Final/tools/godot`，详见 [LUNA.md](LUNA.md)。

### 安装 Python 依赖

需要 **Windows 10 / Windows 11、64 位 Python 3.10～3.12**。当前 OCR 依赖要求 Python 低于 3.13。在项目目录打开 PowerShell：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

也可以使用 uv：

```powershell
uv venv --python 3.12 .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
```

当前工作目录已经创建了虚拟环境并安装了 PySide6 和 RapidOCR 依赖。Python 虚拟环境不适合直接复制到另一台机器，迁移时请重新安装。更新旧版本时，再执行一次安装 requirements.txt 的命令。

文字提取使用随 RapidOCR 安装包附带的本地模型，不需要另装 Tesseract 或下载语言包。翻译需要另外安装并启动 [Ollama for Windows](https://ollama.com/download/windows)，然后下载默认模型：

```powershell
ollama pull qwen2.5:3b
```

默认模型下载量约 1.9 GB，支持中英文等多种语言与 JSON 输出。可以在设置中填写自己已经下载的模型名称。[模型说明](https://ollama.com/library/qwen2.5:3b)

设置中的本机地址默认为 `http://127.0.0.1:11434`，默认译为简体中文。Ollama 的当前 Windows 版本要求 Windows 10 22H2 或更新版本，安装后提供后台服务。[Windows 安装说明](https://docs.ollama.com/windows)

Ollama 和翻译模型尚未在当前工作目录中附带安装；详细配置、操作和待验收流程见 [IMAGE_TOOLS.md](IMAGE_TOOLS.md)。

DeepSeek 对话不需要安装本地模型或新增 Python 依赖。在“设置 → 大模型对话”中填写自己的 API Key，保存后在宠物面板的统一输入框直接提问。算式、单位换算、LC 参数与便签命令自动在本机处理，普通问题发送给大模型。服务地址和模型已经预填，密钥使用 Windows 加密保存。详细步骤见 [CHAT.md](CHAT.md)。

## 启动

双击 **start.bat**，启动时不保留控制台窗口；或运行：

```powershell
.venv\Scripts\python.exe main.py
```

宠物出现在桌面右下附近。左键点击打开工具面板，拖动更改位置，右键打开菜单。隐藏宠物后，点击系统托盘中的莓红色图标恢复。右键宠物或托盘图标选择“退出”可以完整释放快捷键、贴图和后台任务。同一个数据目录只允许运行一个实例。

已接入 `Luna_Final` 动画。退出旧进程后重新运行 **项目根目录的 start.bat** 即可，日常使用不需要启动 Godot。动画触发规则与素材构建说明见 [LUNA.md](LUNA.md)。

动画现已补充姿势进入 / 回位、进入工作及动作收尾过渡；鼠标感应距离扩大到约 200 个逻辑像素，使用 9 个朝向连续插值跟随，并在范围边缘保留缓冲。靠近时使用女仆站姿：两只手都收向小腹，在腹前自然交叠，身体端正站立。更新后请退出旧进程再启动，以加载新版素材清单。

## 快捷键与截图

默认全局快捷键为 **Alt+A**。按下后拖动框选区域，松开后默认立即复制到系统剪贴板，选区仍可继续调整。可在其他支持图片粘贴的软件中按 Ctrl+V。

**Alt+Shift+A** 为区域快速取字：框选松开后本地 OCR，成功直接复制文字；失败保留剪贴板。两组快捷键在设置中独立修改，也可以互换。

- 拖动四角或四边的白色手柄，调整选区大小；拖动选区内部，移动整个选区。
- 在选区外重新拖动，可以重新框选。尺寸实时显示为原始像素。
- **方向键**：移动 1 像素；**Shift+方向键**：移动 10 像素。
- **Ctrl+左右方向键**：缩小 / 扩大宽度；**Ctrl+上下方向键**：缩小 / 扩大高度，左上角保持不动。加按 Shift，每次调整 10 像素。
- **Enter / Ctrl+C**：复制最终选区并结束截图模式。

鼠标调整后松开，或键盘微调短暂停顿后，会更新截图和剪贴板（关闭自动复制时仅更新截图）。工具栏操作始终使用最新选区；结束截图模式时，只将最终图片加入一次历史，不保存每次微调的中间结果。

选区旁显示图标按钮，鼠标悬停时显示文字提示：

- **复制**：再次复制，并结束截图模式。
- **贴图**：生成桌面贴图，并结束截图模式。
- **保存**：结束截图模式后选择保存 PNG 或 JPEG 的位置。
- **标注**：箭头、矩形、文字、马赛克，支持撤销 / 重做、复制、贴图和保存；导出保留原始像素。历史分别保留原图和成功导出的标注版本。
- **提取文字**：关闭截图遮罩，在图片文字窗口自动识别原文。
- **翻译图片**：关闭截图遮罩，识别原文后使用本地模型翻译，并覆盖到图片上。
- **取消 / ESC / 右键**：关闭截图模式。若已经完成选区，保留剪贴板内容，并将最终图片加入历史；拖动过程中取消时保留上一次松开鼠标后的结果。尚未完成任何选区时不保存图片。

设置页可以修改快捷键。支持 Alt / Ctrl / Shift 加字母或数字，以及 F1～F24。冲突时会显示提示并保留此前有效的快捷键，仍可从工具面板、宠物菜单或托盘菜单截图。

## 当前支持功能

### 桌面宠物与工具面板

透明、无边框、置顶的 Luna 窗口，无普通标题栏及任务栏按钮。位置在重启后恢复；如果原位置的屏幕已移除，则回到主屏幕。平常播放普通待机，闲置时约每 12～30 秒随机左右看看或打哈欠；鼠标靠近时才注意鼠标。单击播放疑问，短暂等待连续点击判定后打开面板；快速连续点击升级不满或部位防护。拖动时有提起和落地动作。

截图、提取、翻译与 API 对话期间持板工作；截图结束、文字处理完成、对话回复完成、计算、便签及设置保存成功后庆祝，失败时显示错误反馈。多项操作分别记录忙碌状态，反馈后可继续剩余工作。动画由透明帧按需播放，只缓存少量帧，隐藏时暂停。截图缓存完成后恢复角色工作动画并让鼠标穿透，导出的截图不包含角色。

工具面板出现在宠物附近，点击外部区域自动收起。面板使用统一 Luna 浅色主题，提供输入框、截图、最近图片、贴图数、便签数、提取文字、翻译图片、区域取字和计算记录。计算、便签反馈及大模型回复共用输入框上方的回答区；默认隐藏，根据换行后的内容高度展开，较长内容限制高度并支持滚动，位置按当前屏幕工作区调整。支持自由选字复制、复制全部和收起。点击贴图数量可以恢复隐藏的贴图。

### 区域截图与贴图

截图覆盖所有显示器。每块屏幕独立缓存原始像素；选区内部保留正常亮度，尺寸按实际像素显示。框选后可通过八个手柄缩放选区、拖动内部移动，或使用键盘逐像素微调。跨屏选区按照原始桌面像素拼接，不以某一块屏幕的 DPI 缩放整张桌面。调整过程中沿用同一份屏幕缓存；无显示器覆盖的桌面空隙填充深灰色。

贴图支持置顶、拖动、滚轮等比缩放、双击关闭，以及右键复制、保存、提取文字、翻译图片、透明度、位置 / 大小锁定和鼠标穿透。“恢复贴图交互”从宠物 / 托盘解除锁定和穿透。工作区自动保存，默认重启恢复图片和显示属性，隐藏状态同样保留。可在设置关闭启动恢复；工作区独立于图片历史，最多 50 张、总计 1.28 亿像素。详见 [FEATURES.md](FEATURES.md)。

### 图片历史

自动保存最近 50 张截图，也可将上限设置为 1～50。缩略图网格支持单击预览，以及复制、重新贴图、保存、提取文字、翻译图片和删除。降低上限会删除最旧的记录及其图片文件。

原图与缩略图在单个后台工作线程中编码和写入；索引在主线程原子更新。退出时等待待写入图片并提交索引。历史来源字段预留 screenshot / clipboard / imported，目前只自动收集 screenshot。导入和剪贴板图片可用于提取 / 翻译，不自动加入历史。

### 图片文字与翻译

截图工具栏、贴图右键菜单和历史图片都可直接提取或翻译。宠物面板及托盘提供独立的“提取文字”和“翻译图片”入口，还支持打开本地图片、读取剪贴板图片。

图片在本机用 RapidOCR / ONNX Runtime CPU 识别；OCR 模型在执行时加载，识别结束后释放会话。识别后按照行距、对齐、文字大小、缩进和列表标记将连续正文整理成段落，保留原始行坐标。提取模式为左侧图片、右侧原文；翻译模式为图片、原文、译文三栏。原文和译文是连续纯文本，段落之间用空行分隔，可以跨段拖选、Ctrl+C、右键复制，也可以复制全部；各栏可拖动调整宽度。原文可直接编辑。译为简体中文、繁体中文、英文、日文和韩文；源图识别主要面向中文和英文。

翻译只向本机 Ollama 发送识别后的文字，不发送原图。整段作为一个翻译单元，分批时不拆开段落，并提供相邻段落的上下文，减少逐行翻译导致的语义断裂。采用结构化 JSON 输出并校验段落编号，完整译文分批显示在右侧文本栏。默认左侧保留原图，勾选“图片覆盖译文”可查看覆盖预览：清除原始文字行，在整段区域内重新换行排版，字号上限参考原文字大小。复制图片、保存和贴图使用当前显示的图片；过长的覆盖文字会有提示，完整译文仍可从文本栏复制。

如果自动分段不合适，在原文文本栏中拖选同一栏的相邻段落，点击“合并选中段落”；误合并的未修改段落可以“按原行拆分”后重新选择合并。修改原文立即生效，并清除旧译文，随后重新翻译即可。Enter 新建段落，显示时自动换行不会拆开翻译段落。自由增删段落后仍可翻译文字；原始图片区域无法对应时，本次不生成覆盖图片。需要同时调整覆盖区域时请使用合并 / 拆分按钮。

OCR 和译文绘制使用单个后台工作线程，Ollama 请求使用异步 QtNetwork。支持取消及关闭窗口；旧任务结果不会覆盖新图片。首次模型加载和 CPU 翻译可能较慢，关闭或取消 OCR 后，需要等当前推理返回才释放会话。正常退出会等待后台处理结束。

原文 / 译文中选取文字后，右键可使用对话 API 解释、总结或自定义提问，回复显示在宠物面板。该显式操作会发送选中的文字，图片翻译仍使用本机 Ollama；不上传原图。

### 大模型对话

统一输入框支持中文输入法。面板打开时主动激活窗口，使用工具窗口避免菜单式弹窗的鼠标抓取；跟踪输入法组词状态，候选确认期间的 Enter 不执行命令。点击外部仍收起面板，对短暂的输入法候选窗口焦点切换做延迟判断。此调整尚待用户实际输入法验收。

直接在计算和换算使用的输入框中提问，按 Enter 发送。按格式自动分流：`sqrt(9)`、`25 mm to inch`、`6GHz 1nH` 与 `/note 内容` 使用本机功能，普通自然语言问题使用 DeepSeek；明确的算式或单位参数错误直接显示本地错误。需要强制交给模型时输入 `/chat 内容` 并按 Enter，空的 `/chat` 仅聚焦输入框。服务地址与模型可在设置中修改为其他兼容 Chat Completions 的 HTTPS 服务。默认模型依据 [DeepSeek 当前接入文档](https://api-docs.deepseek.com/guides/codex) 设置为 `deepseek-flash`，还提供 `deepseek-v4-pro` 选项；官方服务默认关闭思考模式，优先快速文字回复。

回复在输入栏上方逐步显示。支持连续上下文、任意文字选择复制、复制完整回答、停止生成、手动重试失败或中断的上一条问题，以及“新对话”清空记录与上下文。点击桌面其他区域会收起面板，生成可继续在后台进行，重新点击宠物可查看；不会自动弹出或抢焦点。本地命令可随时提交，切换到本地功能时停止尚未完成的回复并保留其内容。生成中再次提交模型问题会提示先停止，错误不会自动重试。宠物右键及托盘的“对话记录”保留完整历史窗口，那里仍支持多行消息和继续对话。

默认在本地保存对话，重启后恢复；可在设置中关闭并删除本地记录。API Key 单独使用 Windows DPAPI 加密保存，不写入普通配置或应用日志。接口只在你发送消息或点击重试时调用，不会自动把截图、便签或剪贴板内容发送给远程模型。配置和手动验收步骤见 [CHAT.md](CHAT.md)。

### 快速计算

在宠物面板输入并按 Enter：

| 输入 | 结果 |
| --- | --- |
| `(25*3.3)/7` | `11.7857142857` |
| `sqrt(9)+sin(pi/2)` | `4` |
| `25 mm to inch` | `0.9842519685 inch` |
| `10 cm to m` | `0.1 m` |
| `2.4 GHz to MHz` | `2400 MHz` |
| `6GHz 1nH` | `C = 703.62 fF` |
| `6GHz 700fF` | `L = 1.0052 nH` |
| `1nH 700fF` | `f = 6.0155 GHz` |

支持 `+ - * / ^ ( )`、sqrt / sin / cos / tan / log，以及 pi / e。三角函数使用**弧度**，log 是自然对数。采用受限 AST 解析，不调用 eval；拒绝属性访问、任意函数、非数值对象和过于复杂的表达式。浮点结果用于日常估算，表达式最长 256 字符。

单位换算支持：

| 类型 | 单位 |
| --- | --- |
| 长度 | mm、cm、m、inch、ft |
| 频率 | Hz、kHz、MHz、GHz |
| 时间 | ns、us、ms、s |
| 电容 | fF、pF、nF、uF |
| 电感 | pH、nH、uH |
| 电阻 | ohm / Ω、mohm / mΩ、kohm / kΩ、Mohm / MΩ |
| 功率 | uW、mW、W |

单位区分大小写；µ / μ 可替代 u。LC 输入两个不同类型的正参数，用 `f = 1 / (2π√LC)` 求第三个参数，输出自动选用工程单位。

射频计算入口：`rf help`、`rf q 6GHz 1nH 2ohm`、`rf rp 6GHz 1nH Q=20`、`rf fom 6GHz 1MHz -120dBc/Hz 10mW`。模型定义、公式和核对值见 [RF_CALC.md](RF_CALC.md)，命令在本机执行。

最近 100 条成功计算保存在本地，输入框 ↑ / ↓ 调用表达式并返回原草稿。计算记录窗口支持自由复制、删除、清空、最多 50 个命名收藏。载入表达式只填写输入框，不自动执行。

### 便签与设置

输入 `/note 明天检查 VCO` 创建便签，或在便签列表直接添加。支持完成 / 未完成和删除，立即保存到本地，重启后保留。主面板的便签数量包括已完成的便签。文本按纯文本显示，不解析 HTML 或 Markdown。

设置提供截图 / 取字快捷键、历史上限、自动复制、启动恢复贴图、全屏免打扰、Ollama 地址 / 模型 / 目标语言及 API 对话配置。**开机启动仅预留接口和禁用 UI**。

全屏免打扰默认开启：前台窗口覆盖宠物所在显示器时临时隐藏，退出全屏后恢复；手动隐藏优先。每秒检查一次，不影响贴图或快捷键。特殊窗口可能识别不准，可在设置关闭。

## 用户数据与日志

默认使用 Qt 的 AppLocalDataLocation，在 Windows 下为：

```text
%LOCALAPPDATA%\DesktopPetToolbox\DesktopPetToolbox\
├─ config.json          # 设置和宠物位置
├─ notes.json           # 便签
├─ calculations.json    # 最近计算和命名收藏
├─ pin_workspace/       # 贴图独立原图与 index.json 显示属性
├─ chat.json            # 本地对话原文（开启保存时）
├─ chat_key.json        # Windows DPAPI 加密的 API Key
├─ instance.lock        # 单实例锁
├─ app.log              # 日志，最多 1 MB，保留两份轮换备份
└─ history\
   ├─ index.json        # version + items
   ├─ <uuid>.png        # 原图
   └─ <uuid>.thumb.png  # 缩略图
```

历史记录结构：

```json
{
  "id": "32位UUID",
  "file": "<uuid>.png",
  "thumbnail": "<uuid>.thumb.png",
  "created_at": "UTC ISO 8601时间",
  "source": "screenshot",
  "width": 275,
  "height": 175
}
```

配置、便签和历史索引先写临时文件再原子替换；无法解析的 JSON 会保留为 `.json.broken`，同时记录日志。文件写入失败有错误提示，不会无提示地丢失便签。运行时异常进入日志，操作失败时显示宠物 error 状态及托盘提示。

开发或测试时可设置 `DESKTOP_PET_DATA_DIR` 到独立目录，不必修改源代码，也不必使用硬编码路径。不要在截图运行期间手动移动历史文件。

## 已知问题

- 已在当前 Windows 桌面、单显示器 2560 × 1440、125% 缩放下验证原生 Alt+A 和跨进程粘贴。多显示器、负坐标及混合 DPI 已有模拟测试，**尚未在真实多屏硬件及 Windows 10 上完成验收**。
- 受保护视频、DRM 内容、UAC 安全桌面、独占全屏应用等可能显示黑色或无法截图。截图不包含鼠标指针。
- 跨越不同 DPI 屏幕的选区使用原始像素尺寸拼接，画面物理尺寸一致，文字可能在两块屏幕上呈现不同像素大小。截图过程不支持切换显示器配置；切换前请先取消。
- 选区超过 1 亿像素会拒绝处理，避免大幅占用内存；同屏连续截图只保持一个截图会话。
- 强制结束进程或断电可能留下尚未写入索引的图片文件；正常退出会等待写入完成。请优先使用“退出”菜单。
- 图片文字处理上限为 6400 万像素；OCR 会将长边超过 3200 像素的图片缩小识别，再将文字区域映射回原图。很小、模糊、竖排、手写或复杂排版的文字可能识别不准。
- 译文背景采用邻近像素填充，适合截图、文档和纯色背景；复杂照片、透视变形、重叠文字和很长的译文可能覆盖得不理想。完整译文可在文本栏中复制。
- 自动分段依赖版面规则，不能保证判断所有语义边界；窄栏、表格、相同字号的标题和紧密排列的标签可能需要手动合并 / 拆分。重新提取会使用 OCR 原文替换编辑内容，已修改的段落不会被“按原行拆分”自动丢弃。
- 翻译最多 400 个段落、30000 字符，单段最多 4000 字符；单批请求超时为 180 秒。速度和译文质量取决于本机硬件和所选模型。仅接受本机服务地址和本地模型。
- API 对话首版只支持文字，没有图片输入、文件上传、工具调用或联网搜索。单条问题最多 8000 字符，回复最多 60000 字符；上下文保留最近最多 12 轮完整回复及本次问题，总计最多 32000 字符。模型输出上限为 4096 token，较长任务请分开询问。
- 本地对话最多保留 100 轮、200000 字符，超限删除最旧整轮；中断或失败的回复保留在窗口，但不发送进下一条的上下文。API Key 的解密通常需要相同 Windows 用户及电脑，迁移时请重新填写。API 费用、可用模型及网络状态以服务平台为准。
- 已接入 Luna 角色素材；开机启动、安装包和代码签名尚未提供。目前以 Python 项目形式运行，复制项目时需要保留 assets/luna。
- 标注编辑使用全分辨率缓存，大幅截图的标注重绘可能较慢；关闭未导出的编辑器不保存标注草稿，历史仍保留原始截图。
- 全屏判断依据窗口边界，特殊游戏 / 播放器 / 自绘窗口可能误判；实际 Windows 10 / 11、多屏及 DPI 行为待用户验收。
