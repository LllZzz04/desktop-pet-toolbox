# Luna 最终版 1.0

这是已确认的 **Phase4.17** 动画、素材、骨架和状态机的独立整理版。角色图像、动作参数、表情和遮挡关系均沿用已确认版本。

## 打开预览

解压完整文件夹后，双击 **Start_Luna.cmd**。内附 Godot 4.7.2 Windows 64 位运行程序，首次启动会导入资源。

进入预览后，按 **Space** 自动循环演示全部交互。也可以点左侧按钮或使用以下按键。

| 按键 | 动作 |
|---|---|
| 1 | 普通待机 |
| 2 / 3 | 左右看看 / 困倦哈欠 |
| 4 | 注意鼠标 |
| 5 / 6 | 单击疑问 / 连续点击 |
| Q / W / E | 护头嘟嘴 / 护胸脸红 / 浅蹲护腿脸红 |
| 7 | 拖拽与落地演示 |
| 8 | 进入或退出持板工作 |
| 9 / 0 | 成功庆祝 / 错误反馈 |
| Space | 自动演示开关 |
| D | 骨架和脚底固定调试开关 |

真实鼠标操作：靠近角色会引起注意；同一部位 2 秒内连续点击约 6 次会触发相应防护动作；按住角色并移动可以提起，松开后落地。测试按钮只用于快速预览；真实点击仍受冷却和优先级控制。

## 最终确认内容

- 6.4 秒待机、两次呼吸、轻微重心变化、手部二级运动、腿部网格与脚底固定。
- 独立随机眨眼；呆毛、头发和披风延迟运动。
- 左右看看、哈欠、注意鼠标、单击和连续点击反馈。
- 专用防护手势；护头从前方举手并嘟嘴；护胸和浅蹲护腿使用暖珊瑚色脸红，鼻部已减淡。
- 持板工作使用专用握笔手姿势，平板遮住后方手和笔；保持小幅书写运动，不生成板面文字。
- 拖拽、悬挂、落地缓冲与脚底固定恢复。
- 1.3 秒成功庆祝：蓄力、展开双臂小跳、落地回弹、得意点头；右上方对勾与星光。
- 错误反馈与完整交互状态机接口。

## 文件位置

| 位置 | 内容 |
|---|---|
| `LunaFinalTest.tscn` | 统一预览入口 |
| `LunaPet.tscn` | 可复用角色及状态机入口 |
| `LunaRig.tscn` | 正式骨架、Sprite2D 和 Polygon2D |
| `animations/` | 已确认的动画资源 |
| `controllers/`、`states/` | 交互、动作叠加与状态逻辑 |
| `runtime_layers/` | 34 张已确认的裁剪运行时贴图 |
| `layers/` | 34 张 1536×2304 正式全画布素材，含最终脸部修复 |
| `assets/`、`effects/` | 局部手姿势、表情、眼镜、平板和独立特效 |
| `source/` | 原始 PSD 与早期骨架设计；保持原文件，不回写后续修复 |
| `data/` | 动画目录、图层及裁剪信息、骨架、最终版校验记录 |
| `preview/` | 最终版演示视频、动画总览和已确认动作 GIF |
| `docs/` | 动画目录、接口、素材说明和验收结果 |
| `tests/` | 可重复运行的状态、网格、脚底、眨眼和画面回归测试 |

修改工程：在 Godot 中导入本目录的 `project.godot`，或执行 `Run_Luna_Final.ps1 -Editor`。以后继续开发请复制最终版再改，保留这一份作为冻结版本。

交付范围是 **Godot 动画角色工程与交互状态机**。接入 PySide 或独立透明桌面窗口时，使用 `LunaPet.tscn` 和 [API 说明](docs/API.md)。

使用说明见 [快速上手](docs/QUICK_START.md)，全部动画见 [动画目录](docs/ANIMATIONS.md)，验收记录见 [最终版报告](FINAL_REPORT.md)。
