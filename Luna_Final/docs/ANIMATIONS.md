# 最终动画目录

时长取自已确认的动画资源，不重新制作动作。

| 动作 | 时长 | 说明 |
|---|---:|---|
| `idle_normal` | 6.4 秒循环 | 两次呼吸、重心、四肢和头发披风二级运动 |
| `blink_once` | 0.18 秒 | 独立随机触发，间隔 2.5～6.5 秒 |
| `idle_look_around` | 4.4 秒 | 看左、看右、返回待机 |
| `idle_yawn` | 3.8 秒 | 下沉、闭眼、局部哈欠嘴、恢复 |
| `attention` | 持续 | 平滑朝鼠标微转；离开后恢复 |
| `click_question` | 0.9 秒 | 单击疑问与问号 |
| `click_annoyed` | 1.3 秒 | 短时间三击后的不满 |
| `click_angry_head` | 2 秒 | 从前方护头、嘟嘴 |
| `click_angry_chest` | 2 秒 | 护胸、脸红 |
| `click_angry_legs` | 2 秒 | 先浅蹲再护腿、脸红，双脚固定 |
| `drag_start` | 0.28 秒 | 提起、释放脚底固定 |
| `drag_hold` | 2.4 秒循环 | 弹性跟随鼠标、速度驱动惯性 |
| `land` | 0.85 秒 | 下落接触、缓冲、恢复站立 |
| `working_loop` | 3.2 秒循环 | 专用握笔手姿、眼镜、持板、弱呼吸 |
| `working_exit` | 0.4 秒 | 收回工作道具与姿势 |
| `feedback_success` | 1.3 秒 | 蓄力、小跳展开双臂、落地、得意点头、对勾星光 |
| `feedback_error` | 1.4 秒 | 低头摇头、感叹号和汗滴 |
| `click_angry` | 1.5 秒 | 原有通用兼容资源；普通有效部位六击由三种专用防护动作接管 |

待机变体随机间隔 12～30 秒，交互时暂停触发。单击、三击和六击窗口以及冷却沿用已确认实现；同一部位六击在 2 秒窗口内升级防护，冷却约 2 秒。

## 已确认的局部美术

完整角色不重新生成。局部素材包括哈欠嘴、不满嘴、嘟嘴、成功笑嘴、暖珊瑚色脸红、护头/护胸/护腿手势、工作握笔手、眼镜、工作板，以及问号、怒气、汗滴、对勾、星光和感叹号。

Working 保持最后确认的图层顺序：袖臂 35 → 手及嵌入的笔 39 → 平板 40。板面完全遮挡位于其后且重叠的手臂、手和笔。书写轨迹继续驱动手姿，板面文字输出保持关闭。

脸红以 RGB(244,148,136) 为核心，鼻部透明度乘数 0.12；最终素材和着色器原样冻结。
